# St Paul's Milngavie: home page redesign (concept)

A UI concept for a modern home page for St Paul's Parish Church, Milngavie, with a full-screen photo hero. It is a single static page (`index.html`) with no build step.

This is **not** the official site. The official site is https://stpaulsmilngavie.org.uk/.

- Text, service times and links come from the current home page; photos load from the church's site.
- Hero photo: the sanctuary (chancel and stained glass), `images/hero-sanctuary.jpg`. To change it, replace that file or edit the `.hero-poster` background in `index.html`.
